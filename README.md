# Ody 

This is a compiler for a compiled language called **ody** built from scratch in C++.
<br> <br>
The Main aim of the project is to explore the working of programming languages and the process of designing a compiler for the said language. 
<br><br>
A simple ody code block: 
``` 
fn start() {
    var x = 10;
    var y = 20;
    output(x+y);
}
```
### why ody??
Ody is intentionally kept small enough to be understandable but has enough features so that building its compiler is a meaningful project.
